# Help My Garden - React & Vite UI

This is the front-end user interface for **Help My Garden**, built with modern functional React 19, Vite, Tailwind CSS, Lucide icons, and Motion.

---

## 🌻 Features

- **Front Page with Helping Hand & Romantic Garden**: Poetic botanical illustration featuring a nurturing hand caring for blooming roses and delicate seedlings in a warm cottagecore garden.
- **Address & Geolocation Picker**: Input any address, city, or postal code, or click "Detect My Garden Location" to calculate hardiness zone and seasonal schedule.
- **7 Core Garden Task Modules**:
  1. Pruning Guidance (Frequency, best time, cuts)
  2. Fertilization Schedules (N-P-K, organic feeding)
  3. Pest & Spray IPM (Neem, BT, biological remedies)
  4. Planting by Sunlight (Strictly categorized into **Full Sun**, **Part Shade**, and **Full Shade** with "Best of the best" planting windows)
  5. Harvest Sensory Indicators (Blushing stage, slips, scent)
  6. Post-Harvest Storage & Curing (Dark, cellar, humidity)
  7. Seed Starting (Pre-treatment & duration, germination temp, light vs dark, depth, sprouting days)
- **Local Ollama & Open-Weight Support**: Connects directly to local Ollama (`llama3.2:3b` on Mac M4 Pro) with fallback to built-in botanical knowledge base.

---

## 🏃 Running the UI

cd ui
